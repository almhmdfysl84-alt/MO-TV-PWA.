# MO TV PWA 1.0 — بدون Xcode

نسخة ويب تقدم تجربة MO TV على iPhone وAndroid والكمبيوتر، ويمكن إضافتها إلى الشاشة الرئيسية من Safari/Chrome. لا تحتاج Xcode ولا حساب مستخدم.

## التشغيل
- افتح رابط الموقع على iPhone في Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية.
- يستخدم المشروع Supabase الحالي ويقرأ التصنيفات والقنوات النشطة فقط.
- لا ينشئ حسابات ولا يكتب إلى قاعدة البيانات؛ المفضلة وسجل المشاهدة محليان.
- يشغل روابط HTTPS المتوافقة مع Safari. لا يحتوي على مصادر بث مضافة تلقائياً.
- القنوات في قاعدة البيانات حالياً صفر؛ أضف فقط مصادر تملك حق استخدامها.
- هذه نسخة PWA وليست IPA. لا يمكن إنتاج IPA أو توقيعه من دون Xcode وأدوات توقيع iOS.
- لا تضع مفتاح Supabase السري في ملفات الواجهة.
